# CoverArt

一个 Windows 桌面小窗口：**打开就是一张专辑封面，窗口和封面一样大**。

当前状态：能跑的 Windows 程序（Tauri 2 + WebView2）；想先在浏览器里看效果就双击 `coverart-mini.html`（它就是个外壳，里面装的是程序同一份 `ui/index.html`）。

## 运行与打包

前置：Node 18+、Rust（MSVC 工具链，仓库里 `src-tauri/rust-toolchain` 未固定，用 stable 即可）、WebView2（Win10/11 自带）。

```bash
npm install          # 只装 Tauri CLI，界面本身零依赖、没有打包步骤
npm run dev          # 开发模式：改 ui/index.html 直接生效、热重载
npm run build:exe    # 只出 exe：src-tauri/target/release/coverart.exe
npm run rebuild      # 同上，但先关掉正在托盘里跑的实例（它锁着 exe，否则构建会报 Access is denied）
npm run build        # 出 NSIS 安装包：src-tauri/target/release/bundle/nsis/
```

## 窗口规格（`src-tauri/tauri.conf.json`）

| 项 | 值 | 说明 |
|---|---|---|
| 尺寸 | **560 × 560** | 固定尺寸，改这里就够 |
| 可缩放 | **false** | 拖不了边，也没有最大化按钮（实测无 `WS_THICKFRAME` / `WS_MAXIMIZEBOX`） |
| 边框 | `decorations: false` | 无标题栏，整个窗口就是封面 |
| 拖动窗口 | **整窗可拖** | 按住封面任意空白处移动超过 4px 才开始拖，所以点一下/双击仍然是原来的交互 |
| 右键 | 主窗口里已禁用右键菜单 | `contextmenu` 直接 preventDefault |
| 右上角 ✕ | 收起到托盘（不退出） | 悬浮才出现的磨砂圆钮，和 详情/下载 同一种材质 |
| 关闭 | Alt+F4 / ✕ 都只是收起到托盘 | 真正退出走托盘菜单的「退出」 |
| 翻面后的返回箭头 | 只翻回正面，不会关窗 | 转到背面的那一面设了 `pointer-events:none`——否则正面右上角的 ✕ 会正好压在背面左上角的返回箭头上（`backface-visibility:hidden` 只是不画它，仍然能点到） |

## 托盘

- **左键双击**：显示窗口并置于最前；单击不做事，避免误触
- **右键菜单**：
  - 显示 / 隐藏（跟随窗口当前状态）
  - **置顶**（勾选开关，窗口始终保持在其他窗口之上；选择会记住）
  - 缩放 ▸ **50% / 75% / 100% / 125% / 150%**（勾选当前档位）
  - 轮播 ▸ **关闭 / 5 秒 / 8 秒 / 12 秒 / 20 秒**（每张封面自动停留多久）
  - 退出

缩放同时做两件事：窗口边长 = 560 × 档位，界面 zoom 也按同比例变化——这样「窗口 = 封面」的比例在任何档位都成立，界面里的按钮、字号相对封面的大小始终一致。缩放档位与「置顶」都写进 `%APPDATA%\com.coverart.desktop\prefs.json`，下次启动自动恢复。

## 每日这 20 张

不是"每天现拉 20 张"，而是 **候选池 + 每天从池子里挑 20 张**：现拉只能拉到"当下在榜"的专辑，
历史专辑没有落脚点，所以先把来源攒成本地池子，再从池子里选。

### 一、候选池 `pool.json`（目标 5000 张）

后台慢慢攒，界面不等它。第一次打开会连跑几轮（约 1~3 分钟），之后每次启动补一批。

| 来源 | 拿到什么 | 从国内能不能连 |
|---|---|---|
| **Apple 榜单**：17 个主流市场的播放量榜（前 60）+ 总榜 + 美/英分类型榜（前 25） | 当下主流 | ✅ 稳 |
| **Wikipedia 清单**：Grammy 年度专辑（1959 至今）、全球最畅销专辑、Billboard 200 历年冠军 | 历史经典 | ✅ 稳 |
| **Wikidata**：按年代查最有名专辑（按维基语言版本数排序） | 历史经典（补齐年代） | ⚠️ 国内经常连不上，能连上就用 |

池子里每条记录带：专辑 id、店区、标题、歌手、发行日期、流派、封面基址、**封面指纹**、
榜上最好名次、被几个市场收录、**历史知名度**、**主流度分数 0~100**、档位 **S/A/B/C**、是否经典。

- 入选前先过质量闸：精选集合辑（20+ 种中外写法）、Various Artists 类合辑署名、单曲、翻录盘、
  助眠/白噪音/儿童/圣诞/卡拉OK/lofi 学习音乐、无封面 → 全部丢掉；
- **封面指纹去重**：同一张专辑的 Remaster / Deluxe / Live / Remix 版本合并成一条，
  **保留最早那版**（原版），免得一屏出现三张 The Wall。

### 二、每天挑 20 张（现代 8 / 经典 7 / 混合 5）

| 桶 | 张数 | 怎么抽 |
|---|---|---|
| **经典** | 7 | 从池子里的历史专辑抽，**按年代分配**（60s/70s/80s…），至少跨 3 个年代、单年代最多 3 张 |
| **现代** | 8 | 近 6 年发行的，按主流度加权抽 |
| **混合** | 5 | 不分年代加权抽，其中 2 张是**探索位**（只从 B/C 档里抽，避免整屏都是泰勒·斯威夫特） |

抽签权重 = 档位权重（S 40 / A 24 / B 9 / C 3）× 长期均衡系数（最近 30 天出现得多的流派/年代降权）。

硬约束：

- **专辑 60 天不重复**、**封面指纹 60 天不重复**；
- **同一歌手一天最多 1 张**，且**展示后 7 天冷却**；
- **流派上下限**：Pop ≤5、Rock ≤5、Hip-Hop ≤4、R&B/Electronic/Alternative ≤3、Jazz/Country/Metal/Classical ≤2、其余 ≤3；
- 某条约束把当天名额卡住了就松开重抽，实在不够才少于 20 张。

### 三、其它

- 启动时先看 `daily.json` 里今天这条在不在：**在**就直接用（不联网、秒开）；
- 挑的时候整窗是**一块毛玻璃**（高光渐变 + 扫光条 + 转圈），第一张封面显示出来才撤掉，
  真联网那次至少亮 **700ms**；池子已建好时是从本地挑，几乎瞬间出图；
- 池子还没建起来（< 40 张）→ 退回"现抓一批"的老路径，保证第一屏永远有内容；
- 断网又没缓存 → 退回最近成功的那一天（`stale: true`），一条都没有才弹错误层 +「重试」；
- 展示历史只留最近 **60 天**，跨午夜自动挑新一天的。

`daily.json` 长这样：

```json
{ "days": [ { "date": "2026-09-16", "albums": [ { "id": "…", "sf": "us", "title": "…",
  "artist": "…", "date": "1985-09-16", "genre": "Rock", "tracks": 9,
  "art": "https://is1-ssl.mzstatic.com/…/cover.jpg", "anniv": false } ] } ] }
```

## 每日轮播

默认每 **8 秒**自动切下一张，在今日这一屏里循环（20 张走完回到第 1 张）。档位在托盘菜单里改（关闭 / 5 / 8 / 12 / 20 秒），改完**立刻生效**并记进 prefs.json。

三种停留时长：

| 情况 | 停留 | 说明 |
|---|---|---|
| 自动轮播 | T（8 秒） | 正常节奏 |
| 从挂起回来 | min(剩余时间, 4 秒) | 接着看"挂起前那张"，但不重新计满一轮，也不会干等太久 |
| 用户自己切过的那张 | 1.5 × T（12 秒） | 手动优先：点箭头/滚轮/T 之后，这张多留 50%，下一张恢复正常 |

挂起（不倒数、图不动）的触发条件：**打开搜索浮层、正在看搜索结果、翻到背面看曲目、窗口收进托盘**。恢复：回到今日这一屏（点「每日」/ T / Esc）、翻回正面、窗口重新显示。

两个细节：**计时从"这张图真正显示出来"开始**（网慢不吃观看时间）；**鼠标悬停不暂停**（只有真正的手动操作才算）。

## 收藏

- **右键封面**：心形出现在鼠标位置（未收藏 = 空心，已收藏 = 红心），点它收藏 / 取消收藏。
  **点完先亮 0.4 秒**让你看清结果（红心 / 空心 + 弹一下 + 一圈涟漪），然后干脆地收走；
  落盘失败会回滚状态并抖一下（不假装成功）；没点的情下鼠标动一动续命、停住 2.6 秒收走。
- **本地缓存**：收藏时把封面下载到 `%APPDATA%\com.coverart.desktop\covers\<id>.jpg`（1000×1000），
  **曲目表也一起抓下来存进索引**（收藏的专辑断网也能翻背面）；索引在 `favorites.json`；
  **取消收藏会把本地图片一起删掉**。
- **顶栏第三个标签「收藏」** = 独立的收藏队列：左右箭头、键盘、滚轮、轮播都在这串里走，序号显示 3/12；
  **收藏为空时这个标签置灰不可点**。
- 在收藏视图里取消当前这张 → 从队列里移走并切到下一张；收藏清空 → 自动回到「每日」。
- 收藏的专辑优先用本地封面，所以**断网也能翻**；「原图」仍然需要联网。

## 单实例

程序只允许开一个：再次启动时**第二个进程直接退出**，并把已经开着的那个窗口叫到最前面（`tauri-plugin-single-instance`，注册在所有插件最前面）。实测：连开两个后进程数仍为 1，剩下的是先启动的那个。

## 图标

```bash
node scripts/gen_icon.mjs   # 生成 scripts/icon.png（1024×1024）
npm run icon                # 生成 src-tauri/icons/ 全套（含 icon.ico）
```

`tauri icon` 会顺带生成 `icons/android`、`icons/ios`，Windows 用不到，可以删。

## 界面约定

- 静止时只剩封面；鼠标靠近才出现控件，停下 2.6 秒又收走
- ← → 换封面 ｜ 双击 / 空格翻面看曲目 ｜ 打字或 ⌘K 搜索 ｜ T 回到今天
- 每天一屏 20 张，按日期种子轮换；左上角「发行纪念日」角标在专辑发行当天出现
- 换封面时如果新图还没到（超过 120ms），先把当前这张磨成**毛玻璃**（模糊 + 压暗 + 轻微放大 + 一层暗罩）再切过去，
  而不是一直清清楚楚地留着上一张——快速连点「下一张」或选中搜索结果时尤其明显；命中缓存/预加载时不闪
- 右下角：`3/20` 序号胶囊 + 详情 + 下载原图（⬇ 存到本地，背面「看原图 ↗」是在浏览器里打开同一张 3000×3000）
- 顶栏三格：每日 / 收藏 / 搜索；右键封面出心形收藏，收藏的封面缓存在本地（见「收藏」）
- 每 8 秒自动切下一张（档位可在托盘菜单调，见上），搜索/反面/收进托盘时挂起
- 背面的两个外链交给**系统默认浏览器**打开（Rust 的 `open_external` → `tauri-plugin-opener`）：`Apple Music ↗` 打开专辑页，`看原图 ↗` 打开 3000×3000 原图
- 选中搜索结果后进入「浏览结果」：左右箭头在这串搜索结果里翻（序号显示 `3/22`），顶栏先收起、鼠标一动再回来（两个标签都不高亮）；点顶栏「每日」或按 T 回到今日这一屏
